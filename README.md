A chess engine in at most 4,096 bytes of Python: negamax alpha-beta search with quiescence, MVV-LVA move ordering and a procedural piece-square evaluation, searching to a fixed node budget so every game replays move for move. It plays the make.fun house gauntlet over the env HTTP protocol.

## Run it

```sh
MAKEFUN_ENV_URL=<env url> python3 main.py
```
